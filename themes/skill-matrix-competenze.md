# Skill matrix competenze

## Sintesi corrente

I clienti manifatturieri usano skill matrix cartacee o su Excel per mappare le competenze degli operatori, tipicamente su scala 0-5. In ambito logistica (Danieli), i livelli sono calibrati su righe di prelievo gestibili giornalmente (livello 5 = ~500 righe/giorno). La skill matrix include sia attività operative sia attività "desk" per operatori anziani con limitazioni fisiche. Il problema è che, pur esistendo, la skill matrix non è integrata nei processi di allocazione: le decisioni rimangono mnemoniche. Gabri identifica la digitalizzazione e la dinamicità della skill matrix come punto cardine del TO-BE.
